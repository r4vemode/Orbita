# Живые новости Telegram

Нужны Node.js 22+ (рекомендуется 24 LTS) и Python 3.10+. В двух терминалах, из папки проекта:

1. Сайт: `npm start`.
2. Установка клиента (один раз):

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r telegram/requirements.txt
python telegram/bridge.py
```

На Windows активация: `.venv\Scripts\activate`; при необходимости используйте `python` вместо `python3`.

Создайте приложение в https://my.telegram.org → API development tools.
Введите api_id и api_hash в терминале. Затем клиент запросит номер телефона,
код Telegram и пароль двухэтапной защиты (если включён).
Используйте отдельный аккаунт, которому доступен канал markettwits.
Коды и ключи не отправляйте в чат. Можно задать TELEGRAM_API_ID и TELEGRAM_API_HASH
в окружении процесса. Если сервер использует `ORBITA_DATA_DIR`, передайте тот же
путь процессу Python. Запуск Node с `--env-file=.env` не экспортирует настройки
в другой терминал. Без этой переменной оба процесса используют папку `data` проекта.
Каталог должен быть приватным (0700 в Linux/macOS), вне `public`, без символьных ссылок.
Сессия сохраняется в `ORBITA_DATA_DIR/telegram.session`: это секретный файл,
не передавайте его другим людям и не включайте data в архивы.

Оба процесса должны работать постоянно. Для круглосуточного потока их нужно
запускать на постоянно работающем сервере. Авторизация повторно обычно не нужна.
Не запускайте две копии bridge.py с одной сессией.

Клиент получает новые сообщения и исправления, удаляет удалённые посты,
раз в минуту сверяет последние 200 сообщений. Это также восстанавливает свежую
ленту после перерыва; полная история за длительный простой не обещается.
Сайт получает обновления раз в 20 секунд. При первом открытии старые посты
не вызывают всплывающих уведомлений. Посты без текста пропускаются.

Тональность — консервативные правила, НЕ ИИ и не прогноз цены. Окрашиваются
только однозначные формулировки изменения прибыли одной распознанной компании;
прочее остаётся нейтральным. Указаны актив и причина. Срочность определяется
отдельно, по явной отметке источника. Ожидания рынка правила не учитывают.

Получение через Telegram не предоставляет разрешение на перепубликацию:
условия показа материалов подписчикам необходимо согласовать с источником.

Проверка без подключения: `python3 -m unittest discover -s telegram -p 'test_*.py'`.
Поток считается подключённым только после успешной авторизации и получения постов.
