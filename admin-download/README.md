# Готовый локальный вход в админку

1. Скачайте ZIP ветки `codex/orbita-ready` и распакуйте папку проекта.
2. Windows: откройте `START-ADMIN.cmd` в этой папке. macOS: `START-ADMIN.command`. Нужен Node.js 22+, рекомендуется 24 LTS.
3. При первом запуске вставьте ключ установки из личного чата и нажмите Enter. Браузер откроется автоматически.
4. Войдите с указанными в чате почтой и паролем. Права администратора уже назначены.

Ключ не запрашивается при следующих запусках. `npm install` не требуется. Для запуска из терминала в корне проекта: `node admin-download/setup.mjs`.

Настройка в Git зашифрована AES-256-GCM случайным ключом. В репозитории нет почты, пароля, открытого хеша или ключа расшифровки. Ключ храните в личном чате; удаление папки из Git не стирает историю.

Данные сохраняются в приватной папке `data`, которая исключена из Git. Другие аккаунты, материалы и существующая MFA сохраняются. Повторный запуск не сбрасывает изменённый позднее пароль. Почта не помечается подтверждённой, согласия пользователя не выдумываются. Настройка применима только к локальной версии: сервер слушает `127.0.0.1`, реальные платежи, почта, AI и Telegram не включаются.

После установки папку можно удалить и запускать проект обычной командой `npm start`. В этом случае по умолчанию адрес — `http://localhost:3000/admin.html`. Для публичного размещения отдельно подготовьте конфигурацию и смените локальный пароль.
