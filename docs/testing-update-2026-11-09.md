# Обновлённые тесты и проверка Telegram — 9 ноября 2026

Проверены актуальная навигация, уровни доступа, новый раздел «Рынки», редакция, уведомления, оплата, партнёры и бот. Тесты больше не ждут снятый экран позиций и старый переход каждого клиента на страницу безопасности. Проверки отказа в доступе, изоляции аккаунтов и MFA сохранены.

- `npm run check:ui`: **224 / 224**; все 18 групп прошли на Chromium 154.0.8037.57. [Полный отчёт](qa-launch/ui-current.md).

- `npm run check:mvp`: **13 групп**, без ошибок.

## Исправления приложения, выявленные тестами

1. На новой странице стратегий восстановлено подключение окна обновлений идей. Проверены подписки на стратегию, появление нового уведомления, чтение, закрытие и фокус.
2. Страница стратегии и калькулятор теперь используют `access.tiers` сервера: владелец Exclusive может открыть PRO без отдельного оплаченного периода PRO. PRO не открывает Exclusive.
3. Карточки рыночных данных переносят длинные названия и подписи на узких экранах, включая обе темы.
4. Временная локальная бета явно отключает MOEX и push, чтобы её проверки не запускали внешние источники по умолчанию.

В браузерных тестах исправлены ожидания новой навигации, меню выхода на телефоне, состава стратегий и загрузки статуса бота. Снятый экран участников заменён проверками текущих «Рынков»: права, старые URL, данные/дата/доли контрактов, поиск, фильтры, недоступный источник, безопасный текст, адаптивность и отзыв доступа. Защита прежних API участников также проверяется. Для данных использованы сохранённые тестовые снимки, а не текущие котировки.

## Что проверено у бота

Парсер и тарифы, привязка к администратору, срок/одноразовость кода, проверка secret webhook, недоверенные команды, предпросмотр, создание одной публикации при повторе доставки, история изменения идеи, отзыв привязки/роли, безопасное хранение служебных полей, восстановление очереди и Radar. Браузерная группа включает шесть сценариев веб-настроек и сопровождения Telegram-сигнала.

Подключения к настоящему Telegram API с вашим токеном не было. Транспорт подменяется в автоматических тестах; сетевую доставку нужно проверить вручную. Для Mac нужен токен BotFather и доступный HTTPS-webhook через туннель; одного ID/токена на localhost недостаточно. [Инструкция](../TELEGRAM-ADMIN-LOCAL.md).

## Перед коммерческим запуском

Автоматическая приёмка этой версии завершена. Остаются фактические домен/VPS/TLS, реквизиты и публикация документов, доставка почты, реальные настройки CloudPayments/чеков и тест оплаты/возврата, разрешения на рыночные данные, внешние копии и проверка восстановления, настоящие устройства и реальный Telegram. Зелёные локальные тесты не подтверждают эти внешние подключения.

Исторический неуспешный прогон сохранён в `qa-launch/ui-initial.md` для сравнения; он не описывает текущий результат. В ZIP из GitHub старый персональный установщик исключается через export-ignore, поэтому его три теста штатно пропускаются; они включены в число 468 при запуске в рабочем Git-репозитории.
