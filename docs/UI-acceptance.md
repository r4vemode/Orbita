# ORBITA — приёмка интерфейса

Этот этап проверяет сценарии четырёх ролей в настоящем браузерном движке на временных вымышленных данных. Он дополняет `npm test` и `npm run check:mvp`. Это браузерная автоматизация; личная оценка владельца и работа на физических телефонах отмечаются отдельно.

Результат общего аудита от 31 октября 2026 года: **171/171**. Включены смена аккаунта в открытом кабинете, отзыв доступа в калькуляторе и обучении, поздний ответ MFA, параллельные действия редактора и очистка приватных экранов. Подробности — в [отчёте аудита](project-audit-2026-10-31.md). Предыдущие [проверка позиций и уведомлений](participants-acceptance-2026-10-31.md), [отчёт Radar](radar-acceptance-2026-10-30.md), [приёмка документов](acceptance-2026-10-30.md) и [исходная приёмка](acceptance-2026-10-27.md) сохранены отдельно.

## Повторить прогон

Нужен Node.js 22+, рекомендуется актуальный 24 LTS. Для обычного `npm start` следующие установки не требуются.

```sh
npm ci
npx playwright install chromium
npm run check:ui
```

Сценарии проходят последовательно: аккаунт, редакция, параллельные действия, приватность и смена аккаунта, клиенты, документы и реквизиты, Radar, уведомления идей, позиции участников и адаптивность. Для каждой группы создаётся своя временная база через `startLocalBeta`; рабочие аккаунты и настройки провайдеров не используются. Учебные пароли не печатаются. Сервер принимает соединения только на `127.0.0.1` со случайным портом. После завершения группа останавливает свой процесс и удаляет свои временные данные.

При установленном системном Chromium команда может использовать его. Для другого файла браузера задайте `ORBITA_BROWSER_EXECUTABLE_PATH`; путь не передаётся учебному серверу. Чтобы видеть действия на компьютере с графическим интерфейсом:

```sh
npm run check:ui -- --headed
```

После отдельной установки соответствующего движка доступны `--browser=firefox` и `--browser=webkit`. Успех в WebKit не означает, что пройдена проверка Safari на iPhone.

## Что проверяется

- Регистрация и вход при задержке или отказе загрузки настроек; отсутствие пароля и email в адресной строке; POST как запасной метод формы; актуальная версия согласий и сохранение выбора тарифа.
- Подключение MFA редактора, подтверждение сохранения резервных кодов, вход со вторым фактором и отклонение использованного кода. Ключ и коды остаются только в памяти сценария, не попадают в отчёт и снимки.
- Редакция: быстрый сигнал, уровни, подтверждение входа, стоп, закрытие, отметка ошибки, неизменяемые первоначальные условия; сохранение черновика при переключении и конфликте версий.
- Материалы: черновик, доступ Exclusive, публикация, снятие и конфликт изменений. Настройки: общий результат, сохранение набранного при конфликте, пустые партнёрские URL.
- Pro, Exclusive и бесплатный аккаунт: разграничение страниц, скриптов и API; калькулятор с выбранной стратегией; личный вход и выход, отдельный результат, отслеживание, перезагрузка, отмена и ошибка удаления личной отметки.
- Поиск и прогресс обучения, возврат клавиатурного фокуса после статьи, учебная сделка лонг/шорт, плечо и стоп.
- Выход, кнопка «Назад», смена аккаунта в том же браузере, отзыв подписки в открытом кабинете.
- Реквизиты и документы: закрытый черновик и предпросмотр, экранирование введённого HTML, обязательные поля и контроль ИНН, повторный пароль и свежий второй фактор, отклонение использованного резервного кода, архив редакций и конфликт изменений без потери набранного.
- Radar: лендинг и демо-маркировка, тарифы, поиск и фильтры, разбор и источники, отслеживание, настройки уведомлений, SSE, скрытие/XSS, ручная публикация, конфликт правок, дубли/объединение и отзыв доступа в открытой ленте.
- 22 страницы и раскрытые состояния идеи/полного сценария/статьи на ширинах 320, 390, 768 и 1440. Проверяются переполнение страницы и JavaScript-ошибки; снимки интерфейса доступны для визуального просмотра.

## Отчёт и ограничения

Для каждого запуска создаётся `qa-artifacts/<дата-время-id>/report.md` и `report.json`. Там записаны движок и версия браузера, выполненные сценарии, ошибки и непроверенные внешние условия. Скриншоты содержат только учебный интерфейс. Эти файлы игнорируются Git и не попадают в архив исходников; повторный запуск создаёт новый каталог. Не используйте снимки учебных результатов как рабочую статистику стратегий.

Команда завершается с ненулевым кодом при ошибке. Остановка через Ctrl+C помечает прогон как прерванный; частичный прогон не считается успешной приёмкой. Подмены ответов в отдельных сценариях используются только для задержки/ошибки соединения, без настоящей почты и оплаты.

Отдельно остаются: личная приёмка владельца через `npm run beta:local`, Safari на настоящем iPhone, Chrome на настоящем Android, доставка писем, реальные CloudPayments/Telegram, размещение и бета с участниками. Инструкция по учебным аккаунтам — в [local-beta.md](local-beta.md); условия закрытой беты — в [beta-testing.md](beta-testing.md).
