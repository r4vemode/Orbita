# Калькулятор и историческая OHLC-модель

Калькулятор `/calculator.html` использует опубликованные записи автора и заданные пользователем допущения. Это модель капитала, а не подтверждение исполнения сделок брокером. Учебные идеи по умолчанию исключены; они доступны отдельным режимом. Результаты разных режимов не объединяются.

В расчёте проверяются даты публикации, появления уровней, входа и выхода. Изменение не должно становиться известно раньше его публикации. Учитываются направление, капитал, доля позиции, комиссии и неблагоприятное проскальзывание на обеих сторонах. В статистике показаны количество исполненных сделок, win rate, profit factor, средние результаты и просадка. У калькулятора просадка относится к последовательности закрытий; внутрисделочная переоценка без ценовой истории не моделируется. При отсутствии убытков profit factor не подменяется произвольным большим числом.

## Проверка по свечам

`/backtest-admin.html` доступна только администратору. Данные JSON читаются в браузере, не публикуются как сигналы и не добавляются в статистику стратегии. Без загруженной истории показатели не создаются. Кнопка учебного примера явно маркирует синтетические цены.

Тот же движок доступен локально:

```sh
npm run backtest -- --example > /tmp/orbita-example.json
npm run backtest -- /tmp/orbita-example.json /tmp/orbita-report.json
```

Файл отчёта не перезаписывается: для следующего запуска выберите новое имя. Для Windows используйте путь своего временного каталога вместо `/tmp`. CLI сохраняет SHA-256 точного исходного UTF-8 файла; браузер — SHA-256 `JSON.stringify` импортированного объекта, что отражено в `provenance.scope`.

Формат версии 1 включает:

- `metadata`: источник, `sourceKind` (`real` или `synthetic`), `timezone: UTC`, версия стратегии, дата снимка `asOf`, длительность свечи `intervalSeconds`.
- `instrument`: тикер, рынок, валюта, размер лота, стоимость пункта, шаг цены.
- `options`: капитал, доля позиции, комиссия и проскальзывание в базисных пунктах, срок ожидания заявки в свечах.
- `candles`: время начала и OHLC в строгом порядке, без повторов и перекрытий. Все свечи завершены на дату снимка.
- `signals`: уникальный ID, время публикации, необязательное начало действия, LONG/SHORT, тип заявки limit/stop и уровни. Изменения задают `knownAt` и новый стоп/цель либо отмену ожидающей заявки.

Определение `real` вводит оператор и само по себе не удостоверяет происхождение данных. Отчёт всегда `hypothetical-backtest`; в нём сохраняются источник, версия движка, отпечаток ввода и ограничения. В проект не добавлена выдуманная история реальных результатов.

## Правила и ограничения

- Публикация и изменение применяются только со свечи, открывшейся строго после времени их известности. Текущая незавершённая свеча и изменения после даты снимка отклоняются.
- При гэпе стоп исполняется по худшему открытию. Если внутри свечи достигнуты и стоп, и цель, используется консервативный вариант со стопом и ставится отметка неоднозначности.
- Лимитная заявка не получает исполнение хуже лимита. Проскальзывание для рыночного исполнения направлено против позиции и округляется к шагу цены. Комиссия применяется к входу и выходу.
- Номинал полностью резервируется без плеча; деньги от закрытия внутри свечи доступны следующей свече. Открытая позиция в конце данных не превращается автоматически в закрытую.
- Капитал OHLC-модели переоценивается по закрытиям свечей. Внутрисвечная просадка может быть больше. Отчёт отдельно показывает открытые позиции, неподтверждённое покрытие, разрывы и неоднозначные свечи.
- Дивиденды, корпоративные действия, налоги, финансирование, заём бумаг, обеспечение фьючерсов, объём и доступная ликвидность не моделируются. Для рынков кроме акций выведено отдельное ограничение номинальной модели.
- Ограничения ввода: 16 МиБ, до 100 000 свечей и 5 000 сигналов; расчёт прерывается после 5 миллионов обработок позиций. Большую историю следует разделить на осмысленные независимые сценарии.

Проверки движка используют только искусственные наборы с заранее вычисленными результатами. Для коммерческих утверждений нужны собственная проверенная рыночная история, условия использования данных и независимая сверка результатов.
