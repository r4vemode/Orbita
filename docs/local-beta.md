# ORBITA — покликать локальную бету

Нужен Node.js 22+; рекомендуется актуальный Node.js 24 LTS. Из папки проекта выполните:

```sh
npm run beta:local
```

Команда создаёт отдельную временную учебную базу и запускает сайт только на вашем компьютере, на свободном порту. Она не читает рабочий `ORBITA_DATA_DIR` и не использует параметры реальных платёжных, почтовых или Telegram-провайдеров. Обычный `npm start` продолжает работать с вашей собственной базой как раньше.

В терминале появятся адрес сайта и четыре **учебных** логина с новым случайным паролем для этого запуска:

- **Редакция** — публикация и сопровождение сигналов, статьи, настройки и доступ клиентов.
- **Клиент Pro** — идеи пяти краткосрочных стратегий; Exclusive закрыт.
- **Клиент Exclusive** — среднесрочная стратегия и статьи Exclusive; идеи Pro закрыты.
- **Без подписки** — аккаунт и настройки, без платных сервисов.

Учебные идеи импортируются только в эту временную базу и обозначены как демонстрационные. Цены и результаты вымышлены. Подписки выданы редакцией для проверки интерфейса, без оплаты.

Email учебных аккаунтов не подтверждается вымышленным письмом. После входа сайт может сначала открыть настройки email; откройте напечатанную в терминале ссылку `/admin.html` для редакции или `/app.html` для подписчика. Выданный для локальной проверки доступ не требует онлайн-оплаты. Проверка реальной доставки письма и оплаты остаётся отдельным этапом после подключения провайдеров.

Для проверки нескольких ролей используйте разные браузеры, отдельные профили или приватное окно. Простые вкладки одного браузера делят cookie: вход под другим аккаунтом изменит текущую сессию во всех этих вкладках.

## Что проверить

1. Войдите под редакцией, опубликуйте тикер и направление, затем добавьте уровни и комментарий.
2. В другом браузере войдите под Pro или Exclusive: проверьте свою стратегию и закрытую чужую подписку.
3. Отследите идею, сохраните «Я вошёл», добавьте свой выход.
4. В редакции измените стоп и завершите идею; в кабинете проверьте историю и личный результат.
5. Создайте материал, сохраните черновик, затем опубликуйте для нужного тарифа и снимите с публикации.
6. Под бесплатным аккаунтом проверьте, что прямые ссылки на идеи и обучение не открывают платный контент.

Полная таблица заданий участников — в [beta-testing.md](beta-testing.md). Автоматическая приёмка, включая восстановление копии, запускается отдельно командой `npm run check:mvp`.

## Остановить и начать заново

Нажмите **Ctrl+C** в терминале. Команда дождётся остановки своего учебного процесса и удалит только созданную ею временную базу. Изменения, сделанные во время этого запуска, пропадут. Новый запуск создаст другие пароли и чистые учебные данные.

Если процесс принудительно убит операционной системой, штатная очистка может не выполниться. Не используйте эту временную среду для единственного экземпляра собственных материалов. Для постоянной работы используйте обычный `npm start` и приватный каталог данных с резервными копиями.
