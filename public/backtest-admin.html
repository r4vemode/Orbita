Импорт истории

Файл JSON до 16 МБ остаётся в этой вкладке и не загружается на сервер. Для реальной проверки нужны данные поставщика, версия стратегии и точные даты публикации. Авторство источника и права использования проверяет редактор.

Учебный пример содержит вымышленные цены. Его результаты не входят в опубликованную статистику и не сохраняются в идеях.

Формат и правила расчёта

Обязательны version: 1, metadata, instrument, options, candles, signals. Полную структуру можно скачать кнопкой ниже.

Время указывается в ISO с часовым поясом; metadata.timezone — UTC. Свеча обозначает время открытия, длительность — intervalSeconds. Стратегия использует только данные, известные к открытию свечи. Внутри одной свечи порядок цен неизвестен: неоднозначные исполнения отдельно помечаются.
