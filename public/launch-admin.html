    Пять показателей на старте

    Учитываются клиентские аккаунты. Тестовые платежи и ручная выдача подписки исключены из платёжных показателей; полные возвраты также исключены.

    Перед приглашением участников

    1. Пройдите путь клиента по отдельным аккаунтам Pro и Exclusive.
    2. Подготовьте первые реальные идеи и авторские материалы в редакции.
    3. Запустите локальную приёмку командой npm run check:mvp из папки проекта.
    4. Проведите бету по сценарию из docs/beta-testing.md и устраните критические ошибки.

    Контрольная оплата с возвратом, документы и проверки рабочего размещения выполняются перед открытием продаж.
