# Новости ORBITA

## Запуск
Остановите старый сервер (Ctrl+C), распакуйте полный проект, перенесите свою папку data, запустите npm start. Используйте прежний браузер и http://localhost:3000, чтобы сохранить локальные идеи. В кабинете и калькуляторе появилась кнопка «Новости».

Тест: Новости → Тест уведомления. Тестовое сообщение остаётся в центре; это не публикация MarketTwits. Фильтры выбираются независимо, срочные всплывающие можно отключить. Новости проверяются раз в 20 секунд, только при открытой активной вкладке. При первом открытии накопленная история не всплывает. Одновременно показывается максимум одно уведомление, интервал между новыми — не менее 30 секунд; пропущенные остаются в центре. Всплывают только новые срочные новости выбранных тем не старше 5 минут. Последние 200 новостей находятся в памяти вкладки; локальное хранилище сохраняет настройки и идентификаторы прочитанного, отдельно по аккаунтам. Тексты платной ленты туда не записываются. Это уведомления внутри сайта, не Web Push и не сообщения в Telegram.

## Реальный источник
Автоматическое получение MarketTwits НЕ подключено. В открытых проверенных материалах не обнаружен публичный официальный API/RSS с условиями использования. Контакт из описания официального канала: @MarketTwits_info, info.markettwits@yandex.ru. Нужно согласовать использование заголовков/ссылок в платном продукте и способ доставки обновлений. Наличие Bot API не даёт боту доступ к любому чужому каналу: бот должен быть добавлен в канал.

## Подготовленный приёмник
GET /api/news читает data/news.json. Редактор/будущий коннектор получает данные из согласованного источника и передаёт их в этот формат. Секреты источника нельзя помещать в public.

Формат JSON (пример структуры, не настоящая новость):
```json
{"items":[{"id":"provider-post-123","source":"Название источника","title":"Короткий согласованный заголовок","url":"https://example.com/post/123","publishedAt":"2026-10-19T10:00:00+03:00","topics":["stocks","macro"],"tickers":["SBER"],"urgent":true}]}
```
Темы: stocks, crypto, macro. Максимум 500 записей; идентификаторы стабильные и уникальные, ссылки HTTPS, title до 280 символов. Для ссылок на идеи используются точные тикеры и только активные локальные идеи. Не помечайте весь поток urgent: это редакционное решение. Обновления публикации должны сохранять её id, чтобы не было повторного уведомления.

Импорт подготовленного файла: `node scripts/import-news.mjs /path/to/approved-feed.json`. Команда принимает обычный JSON-файл до 1 МиБ и атомарно заменяет текущий пакет в `ORBITA_DATA_DIR/news.json` (по умолчанию `data/news.json`); передавайте последние новости целиком. Каталог должен быть приватным, вне `public`, без символьных ссылок. Ошибочный входной файл не заменяет предыдущую ленту. Сервер перезапускать после импорта не нужно. Это ручной импорт, не автоматический сбор с Telegram.

Проверены валидация формата, защита ссылок, отсутствие дублей ID, фильтрация будущих публикаций, состояния отсутствующего/ошибочного источника, сохранение учебной карточки при опросе и смене настроек другой вкладки. Реальная доставка Telegram требует отдельного подключения.
