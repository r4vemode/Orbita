# ORBITA / Орбита

Увидеть движение. Понять причину.

Исходники интерактивного прототипа: приветственная страница и кабинет с торговыми идеями. Тёмная сине-платиновая палитра, анимированный фон, переключение идей, разбор сценария и адаптивная вёрстка.

## Запуск в VS Code — Windows и macOS

1. Распакуйте архив.
2. В VS Code выберите File → Open Folder и откройте папку `orbita`, в которой лежит `package.json`.
3. Откройте Terminal → New Terminal.
4. Проверьте наличие Node.js командой `node --version`. Если команда не найдена, установите Node.js с https://nodejs.org и перезапустите VS Code.
5. Выполните:

```sh
npm start
```

6. Откройте http://localhost:3000 в браузере.

Зависимостей нет: `npm install` не нужен. Если PowerShell блокирует команду npm, используйте `node server.mjs`.

Кабинет: http://localhost:3000/app.html

Остановка сервера: Ctrl+C. После изменений сохраните файл и обновите страницу браузера. Автообновление не подключено.

## Где править

- `public/index.html` — приветственная страница.
- `public/app.html` — кабинет и разбор идеи.
- `public/assets/landing.css` — оформление приветственной страницы.
- `public/assets/landing.js` — фон, появление блоков и модальные окна.
- `public/assets/app.css` — оформление кабинета.
- `public/assets/app.js` — примеры сигналов, график и взаимодействия.
- `server.mjs` — локальный сервер на встроенных модулях Node.js.

Сборщика и фреймворка пока нет: обычные HTML, CSS и JavaScript. Можно постепенно переносить компоненты в React, сохраняя этот прототип как визуальную основу.

## Что уже работает

Навигация по приветственной странице, встроенный пример кабинета, переключение трёх идей, раскрытие деталей, список отслеживаемых идей в рамках текущей загрузки страницы, всплывающие сообщения. В кабинете стрелки переключают идеи, Escape возвращает к обзору.

## Что предстоит подключить

Все котировки и результаты — демонстрационные. Регистрация, вход, избранное и личные сделки работают на локальном сервере. Реальные рыночные данные, брокерские операции и платежи не подключены. Telegram-мост подключается отдельно по TELEGRAM-START.md; уведомления об идеях работают внутри сайта.

Шрифт Manrope загружается через Google Fonts; без интернета используется системный шрифт. Анимация учитывает системную настройку уменьшения движения.


## Стратегии и личные сделки

- `strategies.html` — каталог подходов; `strategy.html?strategy=orbita-exclusive` — Orbita Exclusive: идеи на 2–8 недель, разбор тренда, статьи и история прибыльных и убыточных примеров. Каждая стратегия ведёт в калькулятор с готовым выбором.
- В разборе идеи «Я вошёл» сохраняет цену и количество. Можно указать собственный выход; без него открытая позиция оценивается по демонстрационной цене, а завершённая — по цене закрытия автора. Это оценка, не подтверждение брокерской сделки. Сравнение учитывает лонг/шорт; для фьючерсов задаётся стоимость пункта. Комиссии не учитываются.
- Личные сделки авторизованного клиента хранятся в `accounts.json`, отдельно для каждого аккаунта. Гостевые записи сохраняются в текущем браузере и автоматически в аккаунт не переносятся. `ORBITA_DATA_DIR` задаёт каталог серверных данных, по умолчанию `data` рядом с сервером.
- «Обновления идей» показывает публикацию, подтверждение входа, перенос стопа, комментарий и закрытие для отслеживаемых идей или собственных позиций. В настройках можно подписаться на новые сигналы выбранных стратегий. История уведомлений хранится в браузере отдельно по аккаунтам. Всплывающие сообщения работают на открытой странице; события, пропущенные после первого запуска, попадут в центр при следующей проверке. Web Push и доставка в Telegram не реализованы.
- `admin.html` — редактор. После публикации нельзя изменить первоначальный снимок или удалить идею через редактор. Перенос стопа и другие изменения добавляются отдельными событиями с датой МСК. Вместо удаления опубликованной идеи — отметка об ошибке с причиной. Её запись и результат остаются в архиве, но исключаются из расчётов доходности. Старые первоначальные условия явно отмечены как восстановленные, а не подтверждённые исходным снимком.
- Публикации редактора и подписки остаются локальными для браузера и адреса сайта. Журнал защищён от правок через интерфейс и API локального хранилища приложения, но не является независимым серверным аудитом: для публичного сервиса понадобятся общая база, авторизация редактора и серверный журнал.
- `learn.html` — статьи и тренировочная сделка с лонгом/шортом, количеством, стопом и плечом. Доходность позиции и обеспечения показана отдельно. Учебное закрытие по стопу сохраняется до новой сделки; модель не учитывает проскальзывание и реальные правила маржи.
- `brokers.html` — «Где торговать». Поля названий и партнёрских ссылок оставлены пустыми. Для локального заполнения откройте `brokers.html?settings=1` (есть переход из редактора). Для общей конфигурации заполните `public/assets/partners-config.js`. Переходы появляются только для заполненных предложений и явно обозначены как партнёрские.

Проверки без дополнительных npm-зависимостей: `npm test`. Тестируются личные расчёты, приватность аккаунтов и сохранение после пересоздания сервера, публикации и история, результаты стратегий, партнёрские URL и тренажёр. Офлайн-проверки Telegram: `python3 -m unittest discover -s telegram -p 'test_*.py'`.
