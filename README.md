# ORBITA / Орбита

Увидеть движение. Понять причину.

Исходники интерактивного прототипа: приветственная страница и кабинет с торговыми идеями. Тёмная сине-платиновая палитра, анимированный фон, переключение идей, разбор сценария и адаптивная вёрстка.

## Запуск в VS Code — Windows и macOS

1. Распакуйте архив.
2. В VS Code выберите File → Open Folder и откройте папку `orbita`, в которой лежит `package.json`.
3. Откройте Terminal → New Terminal.
4. Проверьте наличие Node.js командой `node --version`. Если команда не найдена, установите Node.js с https://nodejs.org и перезапустите VS Code.
5. Выполните:

```sh
npm start
```

6. Откройте http://localhost:3000 в браузере.

Зависимостей нет: `npm install` не нужен. Если PowerShell блокирует команду npm, используйте `node server.mjs`.

Кабинет: http://localhost:3000/app.html

Остановка сервера: Ctrl+C. После изменений сохраните файл и обновите страницу браузера. Автообновление не подключено.

## Где править

- `public/index.html` — приветственная страница.
- `public/app.html` — кабинет и разбор идеи.
- `public/assets/landing.css` — оформление приветственной страницы.
- `public/assets/landing.js` — фон, появление блоков и модальные окна.
- `public/assets/app.css` — оформление кабинета.
- `public/assets/app.js` — примеры сигналов, график и взаимодействия.
- `server.mjs` — локальный сервер на встроенных модулях Node.js.

Сборщика и фреймворка пока нет: обычные HTML, CSS и JavaScript. Можно постепенно переносить компоненты в React, сохраняя этот прототип как визуальную основу.

## Что уже работает

Навигация по приветственной странице, встроенный пример кабинета, переключение трёх идей, раскрытие деталей, список отслеживаемых идей в рамках текущей загрузки страницы, всплывающие сообщения. В кабинете стрелки переключают идеи, Escape возвращает к обзору.

## Что предстоит подключить

Все котировки и результаты — демонстрационные. Регистрация, платежи, реальные рыночные данные, Telegram и отправка уведомлений не подключены. Отслеживаемые идеи пока не сохраняются после обновления страницы. Модальные окна доступа объясняют состояние прототипа.

Шрифт Manrope загружается через Google Fonts; без интернета используется системный шрифт. Анимация учитывает системную настройку уменьшения движения.
